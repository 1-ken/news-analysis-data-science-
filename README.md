# News Analysis Project

## Description
This project analyzes the engagement of posts from the Hacker News dataset. It specifically focuses on posts that start with "Ask HN" and "Show HN," calculating the average number of comments for these posts and identifying the best times for engagement.

## Installation
To run this project, you need to have Python installed on your machine. You can download it from [python.org](https://www.python.org/downloads/).

## Usage
1. Clone the repository or download the files.
2. Ensure you have the `hacker_news.csv` file in the same directory as the Jupyter Notebook.
3. Open the `News analysis.ipynb` file in Jupyter Notebook.
4. Run the cells to perform the analysis.

## Data Source
The dataset used in this project is `hacker_news.csv`, which contains posts from Hacker News.
